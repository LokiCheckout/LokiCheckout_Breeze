**This Magento 2 module is an add-on package to the LokiCheckout. As of yet, you do not use this module when using a Breeze theme. Just install the `LokiCheckout_Luma` package and it works.**

## Installation
Install this package via composer:
```bash
composer require loki-checkout/magento2-breeze
```

Next, enable this module:
```bash
bin/magento module:enable LokiCheckout_Breeze
```
